⏳ Human pacing engine

Log-normal keystroke intervals, burst-and-rest flow states, finger hesitations, and slowdowns on long lines. It doesn't tick like a bot — it types like hands.

💡 Floating control bar

Always-on-top pause / resume / stop bar with live progress, so you stay in control even while the app types and minimizes itself away.

🔓 Auto-indent aware

Compensates for the editor's automatic indentation so your code comes out exactly right — no doubled or missing indentation.

❓ Optional typos & self-fixes

Rare mistakes that get backspaced and corrected, just like a real session. Toggle them on or off.

💾 Works anywhere

Uses Windows input simulation, so it types into VS Code, the browser, IDEs, terminals — anywhere you put your cursor.

🔑 Privacy first

No accounts, no telemetry, no network. Your code never leaves your machine. Pure Python, open source.

How it works

  1. Paste your code (or load it from a file / clipboard).
  2. Pick a speed and toggles: jitter, thinking pauses, typos.
  3. Click Start Typing and focus VS Code during the countdown.
  4. Use the floating bar to pause, resume, stop — or press F8.

FAQ

Do I need to install Python?

No. The .exe is fully self-contained. Download, run, done.

What is this for?

Creating demo videos, streams, tutorials and screen recordings where typing code live looks better than pasting it. Keep it to content you own — don't use it in proctored exams, interviews or anything that prohibits automation.

Does it work in every editor?

Any app that accepts keyboard input on Windows. It's tuned for VS Code's auto-indent behavior; other editors may need "Fix editor auto-indent" toggled off.
